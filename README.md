## Що зроблено
* **Заняття 3:** проєкт запущено, перемкнуто набір артів.

У першому юніті я з нуля зібрав основу для гри. Спочатку відкрив MainScene і закинув туди Tilemap для підлоги, одразу виставивши Order in Layer на -10, щоб фоновий шар нічого не перекривав. Далі додав персонажа PlayerCharacter та поставив йому PPU 64, щоб пікселі виглядали чітко й не розмивалися. Після цього написав скрипт PlayerController, де прив'язав рух до нової системи InputAction та помножив швидкість на Time.deltaTime, щоб персонаж ходив однаково на будь-якому ноуті. Насамкінець намалював і закинув у проєкт карту level_plan.png, де позначив спавн гравця на (X: -2, Y: 0), тайли доріжок, предмет для підбору та будинок для завершення рівня.
